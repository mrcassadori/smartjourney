## Overview

**Inter** (anteriormente Banco Inter) é o maior super app financeiro do Brasil, combinando conta digital, cartão de crédito, investimentos, seguros, marketplace (Inter Shop), câmbio (Global Account) e empréstimos numa única plataforma. Com mais de 43 milhões de clientes e listagem na NASDAQ (INTR), o Inter representa a evolução do banco digital brasileiro para um ecossistema financeiro completo.

### Números

| Métrica | Valor |
|---------|-------|
| Clientes | 43M+ (2025) |
| Receita Bruta | R$ 10B+ (2024) |
| Lucro Líquido | R$ 973M (2024) |
| Listagem | NASDAQ (INTR) + B3 (INBR32) |
| Verticais | Banking, Investimentos, Seguros, Marketplace, Câmbio |
| Rebrand | 2024 (Plau Design) |
| Tipografia Customizada | Citrina (Plau Design – Carlos Mignot, Rodrigo Saiani) |

### Princípios de Design

1. **Simplicidade** — Interfaces limpas com hierarquia clara; reduzir atrito ao mínimo
2. **Confiança** — O laranja transmite energia e acessibilidade; backgrounds brancos comunicam transparência
3. **Unificação** — Um super app, uma linguagem visual consistente entre banking, shopping e seguros
4. **Modernidade** — Formas geométricas, tipografia contemporânea, animações sutis
5. **Acessibilidade** — Design inclusivo para os 43M+ de clientes em diversas faixas etárias e perfis

### Características Técnicas

- **Super App Architecture** — Uma única aplicação com módulos de banking, marketplace, seguros, investimentos e câmbio
- **Citrina Typeface** — Tipografia customizada com eixos de variação (weight + optical size), desenhada pela Plau Design
- **Orange-first Branding** — Laranja (#FF7A00) como cor primária dominante em toda a comunicação
- **Geometric Language** — Formas geométricas com terminais levemente arredondados (inspiração Futura com twist moderno)
- **Cashback Economy** — UI otimizada para exibição de cashback, promoções e marketplace

### Uso Estratégico do Laranja

O laranja não é usado em backgrounds extensos — é aplicado cirurgicamente:
- **Logo e marca** — Sempre presente no header/splash
- **CTAs primários** — Botões de ação principal (abrir conta, investir, comprar)
- **Highlights** — Valores de cashback, porcentagens de retorno, badges
- **Indicadores** — Progress bars, status ativo, current tab
- **Nunca em texto corrido** — O laranja em corpo de texto prejudica legibilidade

## Typography

### Citrina — A Tipografia Proprietária

A **Citrina** é a família tipográfica bespoke do Inter, desenhada pela **Plau Design** (Carlos Mignot, Rodrigo Saiani) como parte do rebrand de 2024 quando o Banco Inter se tornou **Inter & Co**.

#### Origens e Conceito

O nome "Citrina" evoca a fruta cítrica — vibrante, fresca e energética como o laranja da marca. O design parte do ampersand do "Inter & Co" como ponto focal, simbolizando parceria e unidade. A fonte traz influências do classicismo geométrico da Futura mas com personalidade contemporânea: x-height generosa, formas "o", "c" e "e" arredondadas criando ritmo visual dinâmico e acessível.

#### Especificações da Família

| Dimensão | Valores |
|----------|---------|
| Optical sizes | 2: **Text** (app, UI, corpo) e **Display** (títulos, marketing, hero) |
| Eixos de variação | 2: Weight + Optical Size |
| Weights | Light (300), Regular (400), Medium (500), Bold (700), Black (900) |
| Formato web | Variable font (reduz file size e requests) |
| Influências | Futura (geométrica) + twist contemporâneo |

#### Citrina Text — Interface

- Projetada para tamanhos pequenos em tela (12–18px)
- x-height generosa para legibilidade digital
- Espaçamento refinado em tamanhos menores
- Ideal para: UI do super app, saldos, extratos, labels, corpo de texto

#### Citrina Display — Comunicação

- Projetada para tamanhos grandes (24px+)
- Maior personalidade e expressividade
- Terminais arredondados mais pronunciados
- Ideal para: headlines do site, campanhas, marketing, hero sections, cartões

### Fallback Stack

```css
font-family: 'Citrina', 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
```

Para contextos onde a Citrina não está disponível (e-mails, PDFs de terceiros), o fallback principal é a fonte Inter (open-source) por similaridade geométrica.

## Elevation & Depth

### Filosofia

O Inter segue abordagem **predominantly flat** no light mode, usando separação por cor de background (branco vs cinza claro) como principal mecanismo de hierarquia. Sombras são reservadas para elementos que genuinamente flutuam (FABs, sheets, modais).

### Box Shadows (Light Mode)

| Token | Box-shadow | Uso |
|-------|-----------|-----|
| `elevation.none` | Nenhuma | Elementos inline, flat, seções |
| `elevation.low` | `0 2px 8px 0 rgba(0,0,0,0.06)` | Cards em repouso, lista de transações |
| `elevation.medium` | `0 4px 12px 0 rgba(0,0,0,0.10)` | Cards elevados, dropdowns, tooltips |
| `elevation.high` | `0 8px 24px 0 rgba(0,0,0,0.14)` | Bottom sheets, modais, overlays |
| `elevation.highest` | `0 16px 40px 0 rgba(0,0,0,0.18)` | Full-screen modais |

O Inter favorece formas com **cantos generosamente arredondados** — especialmente botões pill e cards com radius 12–16px. A linguagem visual é suave e acessível, evitando ângulos retos que transmitam rigidez bancária tradicional.

### Iconografia

- **Estilo**: Line icons com stroke consistente (1.5–2px)
- **Tamanho base**: 24px (touch target mínimo 44x44px)
- **Cores**: Monocromáticas (cinza escuro default, laranja para estados ativos)
- **Quick Actions**: Ícones dentro de círculos com background sutil (#F5F5F7)
- **Categoria de transação**: Ícones categóricos (alimentação, transporte, saúde, etc.)

### Logo

- **Marca**: "inter" em lowercase, bold, geométrica, terminais levemente arredondados
- **Cor principal**: Laranja (#FF7A00) sobre branco
- **Versão alternativa**: Branco sobre fundos escuros
- **Spacing**: Generoso — nunca encostado em outros elementos
- **Proibições**: Nunca em cores que não sejam laranja ou branco; nunca distorcido ou rotacionado

## Do's and Don'ts

### ✅ Do's

- **Use o laranja com intenção** — Aplicar somente em CTAs primários, logo, highlights de cashback e indicadores ativos. O laranja é precioso por ser escasso
- **Mantenha backgrounds brancos dominantes** — O branco transmite transparência e confiança no contexto financeiro
- **Use Citrina para identidade** — A tipografia customizada diferencia o Inter de concorrentes e dificulta fraudes
- **Priorize contraste** — Mínimo 4.5:1 para texto, especialmente em valores monetários que requerem leitura precisa
- **Aplique border-radius generoso** — Pills em botões (999px), 12–16px em cards. A linguagem é suave, não rígida
- **Respeite a hierarquia por peso** — Bold/Black para headlines, Regular para corpo, Light para valores numéricos grandes
- **Use flat design com separação por background** — Preferir alternar branco/#F5F5F7 em vez de múltiplas sombras
- **Teste em ambos os modos** — Light mode é o padrão, mas dark mode precisa manter identidade e legibilidade
- **Numerais tabulares em tabelas** — Extratos, listas de transação e comparações requerem alinhamento numérico

### ❌ Don'ts

- **Não use laranja em texto corrido** — O laranja sobre branco não atinge contraste WCAG para corpo de texto (body)
- **Não abuse de sombras** — O design é predominantemente flat; sombras são reservadas para elementos flutuantes
- **Não use preto puro (#000000) para texto** — Preferir #161616 ou #1D1D1D para conforto visual
- **Não substitua Citrina por qualquer sans-serif** — Se Citrina não estiver disponível, o fallback é a fonte Inter (rsms), não Arial ou Helvetica
- **Não coloque laranja sobre laranja** — Nunca usar variações de laranja como background + texto simultaneamente
- **Não use ângulos retos em CTAs** — Botões são sempre pill-shaped ou com radius generoso; nunca square buttons
- **Não quebre a consistência entre verticais** — Banking, Shop, Seguros e Investimentos compartilham a mesma linguagem visual
- **Não use tipografia com serif** — O Inter é 100% sans-serif; nunca introduzir serifs na interface ou comunicação
- **Não inverta apenas as cores para dark mode** — O laranja em dark mode é ligeiramente mais claro (#FF9B3D) para manter contraste e evitar "muddiness"
- **Não replique a identidade para fins fraudulentos** — A Citrina é proprietária e serve como mecanismo anti-phishing
